This deck is based on a university-level Operating Systems course taught in Italy, with a focus on Linux internals and basic Bash commands.

The cards cover both theoretical foundations and practical concepts (with exercises), including:

* Operating system structure and layering
* Kernel vs user space, privilege levels, and execution modes
* System calls and their implementation in Linux
* Monolithic, microkernel, and hybrid kernel architectures
* Process, memory, file system, and I/O management
* Core GNU/Linux components and the role of the C standard library
* Essential Linux and Bash concepts

Many cards also have diagrams and/or videos for better understanding (plus some interactive simulations!)
